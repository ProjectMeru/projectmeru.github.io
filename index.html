Project Meru is an open-source initiative that will host many projects — each with its own problem space, licence clarity, and product surface. The first is Sumeru, a modular ERP framework in Go.

02 / Why Meru

One initiative.
Many sharp tools.

01

Clear names

The organisation is Meru. Products keep their own names — Sumeru in the code, CLI and modules — so search, licences and docs stay unambiguous.

02

Category room

ERP is first, not last. The hub is structured so tooling, infra and future categories can sit beside Sumeru without crowding its product site.

03

Honest shipping

Pre-alpha means pre-alpha. We would rather publish gaps than hide them behind a feature matrix.

03 / Featured

Sumeru, today.

An open-source modular ERP: addons for contacts, products, CRM, sales, invoicing and more, on a Go kernel with plain PostgreSQL tables.

For engineers

Three Go modules, generated blank imports, XML views, event bus, JSON-RPC API. Get from empty database to setup wizard in minutes.
