    Relational field limits

    • Many2one — stored as BIGINT FK; fully supported for CRUD and search.
    • Many2many / One2many — no direct column on the parent table. UI can display relations; persistence is limited. Special cases (company_ids, security_group_ids) have dedicated handling in the kernel.
    • Do not assume Odoo-style M2M/O2M write-through on arbitrary models without verifying behaviour.

    Model inheritance

    ORM model _inherit is not supported. Extend behaviour with bridge modules, view XML inherit, or new models — not by merging Go struct definitions.
