    Field types

    Models embed sdk.Model and use typed field markers from sumeru/core/sdk. Schema is inferred at registration from Go types and sumeru struct tags. For declaration examples see Models & fields.

    Derived fields

    Any scalar marker can carry:

    • related=other_field.subfield — read-only mirror of a related value (no separate column logic beyond the source).
    • compute=name — filled by a handler registered with orm.RegisterCompute; optional store persists to the column on write; readonly blocks client edits.

    Common struct tags

    required, unique, index, default=, string= (label), column=, size=, precision=, scale=, currency=, min=, max=, comodel=, inverse=, ondelete=, table=, left=, right=, model_field=, related=, compute=, store, readonly, groups=

    Typed selections do not use inline selection= tags — define const blocks and use sdk.Selection[YourType].

    Registration

    Generated models/zmodels.go calls sdk.MustRegister on make generate. Authors do not write Fields() or hand-register models in addon init(). Cross-module relation types come from generated models/zrefs.go after listing modules in depends.
