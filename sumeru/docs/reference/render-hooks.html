    Render hooks

    Package: sumeru/core/engine/render

    The render layer turns sys.view records and ORM data into HTML for the workspace shell.

    Form views: Record forms in the workspace are rendered client-side by SWC (sumeru/core/swc/src/views/FormView.ts, form-sheet.ts). Field widgets live in sumeru/core/swc/src/widgets/ with registration in registry.ts. Go form_render.go and related files were removed; the CSS contract remains in sumeru-views.css / sumeru-workspace.css.

    Render package layout

    FileRole
    view_render.goRenderView — selects list/kanban/pivot (form → SWC)
    ~~form_render.go~~Removed — form UI is SWC
    list_render.go, kanban_render.go, pivot_render.goList, kanban, and pivot views
    activity_chatter_render.goMessages tab (mail)
    shell_render.go, menus.go, pinned_apps.goTop bar, sidebar, pins
    render_types.goPageData, hooks registration

    Form Edit / Save / Cancel is owned by SWC FormView.ts (sumeru/core/swc/src/views/FormView.ts), not a Go chrome file.

    Shell hook

    Inject HTML into the top bar area:

    go
    go
    render.RegisterShellHook(func(ctx context.Context, vr *render.ViewRecordData, ro bool) template.HTML {
    return template.HTML(`<div class="my-hook">...</div>`)
})

    Example: sumeru/addons/sumeru_ai/init.go

    Notebook hook

    Replace a notebook page body for a given model and tab title:

    go
    go
    render.RegisterNotebookHook("core.partner", "ai insights", func(ctx context.Context, vr *render.ViewRecordData, ro bool) template.HTML {
    return template.HTML(`<p>Placeholder content</p>`)
})

    Kanban group expander

    Custom column loader for grouped kanban boards (SWC workspace). Package: sumeru/core/engine/swcmeta

    go
    go
    swcmeta.RegisterKanbanGroupExpander("crm.lead", "stage_id", expandFn)

    Expander functions return []swcmeta.KanbanColumn. Example: sumeru_addons/crm/services/hooks.go (pipeline and forecast kanbans).

    Styles

    Core CSS: core/engine/assets/css/. Workspace pages add sumeru-workspace.css. Per-page sheets (home, apps, settings) register via PageData.ViewStylesheetURLs.
