    Widgets and views

    Reference for workspace view XML parsed by core/engine/render/parser/view_xml.go and rendered by core/engine/render/.

    View types

    TypeStatusPurpose
    formImplementedSingle-record edit
    listImplementedTabular list
    kanbanImplementedBoard grouped by a field
    pivotImplementedRead-only HTML aggregation table (v1)

    Pivot fields

    On type="pivot" views, set a role on each nested :

    Field attributeRole
    type="row"Row axis (group labels down the left)
    type="col"Column axis (group labels across the top)
    type="measure"Numeric value summed per cell
    <view id="view_sale_order_pivot" model="sale.order" type="pivot">
    <field name="partner_id" type="row"/>
    <field name="date_order" type="col"/>
    <field name="amount_total" type="measure"/>
</view>
    • Aggregates up to 500 rows from the current action domain (maxWorkspaceListRows).
    • Read-only HTML table — no CSV/PDF export, drill-down, or graph view.
    • Empty arch (no row/col/measure fields) shows a placeholder prompting configuration.
    • Include pivot in window action view_mode, e.g. tree,form,pivot.

    View inheritance

    Extend existing views with xpath — see View inheritance. Supported xpath: //field[@name='x'] with position="after|before|inside|replace".

    Model _inherit is not supported — only view arch inherit.
