Editions & licensing

What you can use today and under which license.

Community edition (today)

All code in the public Project Meru / Sumeru repositories ships as a single community edition:

  • License: Apache 2.0
  • Includes: Core engine, kernel addons, standard business apps (sumeru_addons)
  • Cost: Free to use, modify, and distribute under Apache 2.0 terms
    There is no separate paid installer or feature gate in the open-source tree at this time.

Pre-alpha status

Sumeru is pre-alpha regardless of edition:

  • No tagged stable release
  • No guaranteed upgrade path between versions
  • Limited automated tests on business addons
  • Do not run production or live business workloads
    Evaluate for development, demos, and contribution — not as your system of record yet.

Enterprise / commercial

A separate commercial offering may be described on the Project Meru website in the future. The documentation here describes the open-source tree only.
For legal text, read the LICENSE file in each repository.

Contributing

Contributions welcome under project contribution guidelines. Apache 2.0 applies to contributions accepted into the main trees.
