    Glossary

    TermMeaning
    AppInstallable business module (CRM, Sales, …) shown on Home
    PartnerCustomer, vendor, or contact (core.partner)
    LeadEarly-stage sales contact in CRM
    OpportunityQualified deal in the sales pipeline
    StagePipeline column (e.g. Qualified, Won)
    QuotationDraft sales offer before confirmation
    Sales orderConfirmed customer order
    InvoiceCustomer bill (outgoing)
    BillVendor invoice (incoming)
    PostFinalize accounting entries on an invoice or bill
    Register paymentRecord money received or paid against an invoice/bill
    ReconcileMatch payment to invoice so balances clear
    RFQRequest for quotation to a vendor
    Purchase order (PO)Confirmed order to a vendor
    UTMUrchin Tracking Module — campaign/medium/source attribution
    WorkspaceMain screen for lists, forms, and kanban views
    KanbanBoard view with draggable cards
    ActivityScheduled follow-up task on a record
    ReportToolbar action to download CSV/PDF or bulk-import CSV (when enabled on a view)
    Bulk importLoad many records from a CSV via mapping and preview before save
    Column mappingMatching each CSV column header to a field (or Skip) before import
    Import templateEmpty CSV with correct column headers for bulk upload
    UpsertCreate new records or update existing ones when id is provided
