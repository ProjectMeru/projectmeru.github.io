    Build your first module

    Follow this path when you want a custom addon in sumeru_custom_addons/addons/ without guessing the order of steps.

    Checklist

    StepWhat you doDeep dive
    1Install Sumeru and PostgreSQLInstallation
    2Configure sumeru_custom_addons workspaceCustom addons workspace
    3Scaffold or explore the kitchen-sink demoCreating an addon
    4Declare manifest.json and dependsManifests & depends
    5Define Go models and run make generateModels & fields
    6Add list/form XML and window actionsViews & menus
    7Install the module onceInstall a module
    8Wire menus to actionsAdd menu and action
    9Study the live reference moduleEngagements cookbook

    Step 3 — model + view together

    Your model name in Go must match the model= attribute in XML views and actions.

    models/engagement_project.go (excerpt) 
    1type EngagementProject struct {2	sdk.Model `sumeru:"model=engagement.project"`3 4	Name  sdk.String `sumeru:"required,unique,index,string=Engagement Name"`5	State sdk.Selection[ProjectState] `sumeru:"required,string=Status,default=draft"`6}
    views/list_view.xml (excerpt) 
    1<view id="view_engagement_project_list" model="engagement.project" type="list">2    <field name="name"/>3    <field name="state"/>4</view>

    Run make generate after editing Go structs, then -u your_module (or reinstall) after XML changes.

    Step 7 — install

    $cd sumeru_custom_addons$make install MODULES=my_app
