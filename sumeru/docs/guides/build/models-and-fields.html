    Models & fields

    ModelName, Fields, field types, relations and how runtime records are maps.

    BaseModel and registration

    Prefer sumeru/core/sdk over importing sumeru/core/orm directly. Embed sdk.BaseModel, implement ModelName() and Fields(), register in init with the addon's technical name.

    addons/my_module/models/models.go
    go 
    1package models2 3import (4	"sumeru/core/sdk"5)6 7// MyModule represents the primary record for My Module.8type MyModule struct {9	sdk.BaseModel10	Name        string `db:"name"`11	Description string `db:"description"`12	Active      bool   `db:"active"`13	Sequence    int    `db:"sequence"`14}15 16func (m *MyModule) ModelName() string {17	return "my.module"18}19 20func (m *MyModule) Fields() []sdk.FieldDefinition {21	return []sdk.FieldDefinition{22		{Name: "name", Type: sdk.Char, String: "Name", Required: true, Index: true},23		{Name: "description", Type: sdk.Text, String: "Description"},24		{Name: "active", Type: sdk.Boolean, String: "Active", DefaultVal: "true"},25		{Name: "sequence", Type: sdk.Integer, String: "Sequence", DefaultVal: "10"},26	}27}28 29func init() {30	sdk.RegisterModel(sdk.RegisterModelInput{Model: &MyModule{}, Module: "my_module"})31}

    Computed fields

    Register derived values with orm.RegisterCompute in core or addon init(). Computed fields are filled on read via ApplyComputes. This is not runtime model inheritance or automatic write-time recomputation — declare deps explicitly and keep logic in Go.

    init.go
    go 
    1orm.RegisterCompute("sale.order", "amount_display", []string{"amount_total"},2    func(ctx context.Context, rec map[string]interface{}) (interface{}, error) {3        return fmt.Sprintf("%.2f", rec["amount_total"]), nil4    })

    Runtime records are maps

    ORM reads and writes use map[string]interface{} keyed by field name (plus id). Struct tags like db:"name" document columns; schema sync follows Fields().

    Compile and run

    Terminal
    shell 
    $make generate$go run . -- -c sumeru.conf -i my_module --stop-after-init$make run

    Schema sync. Install/update syncs columns from FieldDefinition. Review migrations on shared databases. Sumeru is pre-alpha.

    What not to do

    • Do not register a model with a Module that differs from manifest.json name.
    • Do not invent FieldType strings outside the constants above.
    • Do not put business logic that must survive restarts only in struct methods the ORM never calls.
