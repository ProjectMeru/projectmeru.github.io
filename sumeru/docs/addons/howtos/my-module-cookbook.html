    my_module kitchen-sink demo

    Reference addon for custom-module authors in sumeru_custom_addons/addons/my_module/. Use it to learn widgets, views, zrefs, and menu patterns — copy patterns, do not fork the module for production work.

    Scaffold vs demo

    make new MODULE=x Pre-shipped my_module
    Models 1 stub 6 models
    Views list, form, kanban All 10 view types + search
    Depends base base, hr, mail
    Use when Starting a real module Learning SWC widgets and XML

    Get it running

    From sumeru_custom_addons/ (after [Installation](../../guides/start/installation.html)):

    
        make setup

        make install MODULES=my_module

        make run

    Open the My Module app in the launcher. Demo rows load from data/demo.xml (noupdate="1", upsert on unique keys).

    Models

    Model Purpose
    my.module Field/widget cookbook (kanban, list, form, calendar, gantt, graph, pivot, cohort)
    my.module.line One2many child lines
    my.module.event Calendar + gantt (date_start / date_stop)
    my.module.place Map markers (latitude / longitude)
    my.module.tag Many2many tags + color
    my.module.category Many2many categories

    Menus and view modes

    Menu Action View modes
    Cookbook operations → Records action_my_module kanban, list, form, calendar, gantt
    Cookbook operations → Lines action_my_module_line list, form
    Cookbook planning → Events action_my_module_event calendar, gantt, list, form
    Cookbook planning → Places action_my_module_place map, list, form
    Cookbook reporting → Analysis action_my_module_analysis graph, pivot, cohort, list
    Configuration → Tags / Categories manager list, form

    Search views attach to collection toolbars (not separate menus). See views/search_view.xml.

    Cross-module relations (zrefs.go)

    Manifest depends on base, hr, mail. After changing depends or model fields that reference other modules:

    
        make generate

        make update MODULES=my_module

    make generate rewrites models/zmodels.go and models/zrefs.go. Edit hand-written model files only.

    Typed selections: models/selection_types.go. Computes: models/computed.go. Object actions: models/object_actions.go.
