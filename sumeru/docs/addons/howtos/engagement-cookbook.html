    Engagements Cookbook

    Tutorial business app for custom-module authors in sumeru_custom_addons/addons/engagement_cookbook/. Models a client engagements practice while teaching widgets, views, depends, model inherit, view xpath inherit, and event bridges.

    Scaffold vs cookbook

    make new MODULE=xengagement_cookbook
    Models1 stub6 business models + partner inherit
    Viewslist, form, kanbanAll 10 view types + search
    Dependsbasebase, contacts, hr, mail
    Use whenStarting production workLearning full addon patterns

    Get it running

    From sumeru_custom_addons/:

    make setup
make install MODULES=engagement_cookbook
make run

    Open Engagements Cookbook in the launcher. Demo engagements, deliverables, milestones, sites, and partners load from data/demo.xml.

    Inheritance examples

    Model inherit

    PartnerEngagement in models/partner_extend.go:

    type PartnerEngagement struct {
    sdk.Model `sumeru:"inherit=core.partner"`
    EngagementTier   sdk.Selection[EngagementTier] `sumeru:"string=Engagement Tier,default=standard"`
    StrategicAccount sdk.Boolean                 `sumeru:"string=Strategic Account,default=false"`
}

    Run make generate then -u engagement_cookbook so schema sync adds columns to core_partner.

    See also: kernel demo in sumeru/addons/contacts/models/partner_extend.go and Model inherit how-to.

    View inherit

    views/partner_inherit_views.xml xpath on contacts.view_core_partner_form:

    <record id="view_engagement_partner_inherit" model="sys.view">
    <field name="inherit_id" ref="contacts.view_core_partner_form"/>
    <field name="arch" type="xml">
        <xpath expr="//field[@name='phone']" position="after">
            <field name="engagement_tier" string="Engagement Tier"/>
            <field name="strategic_account" string="Strategic Account"/>
        </xpath>
    </field>
</record>

    Event bridge

    hooks.go promotes client tier when a project reaches done:

    func init() {
    event.Subscribe("record.updated", onProjectDoneUpdatePartner)
